TRANSPARENT BY DESIGN

Know what the numbers mean.

Entropy & guessing models+

For each distinct character, pᵢ is its frequency divided by password length n. We calculate H = −Σ pᵢ log₂(pᵢ), then show n × H in bits and H in bits per character.

This is empirical character entropy. It cannot measure the randomness of the process that created one password. The score instead uses zxcvbn’s dictionary, keyboard, repetition, date, and substitution guessing model. Guesswork bits = log₂(estimated guesses).

Exhaustive-search time = Nⁿ / (2 × rate). Pattern-attack time = estimated guesses / rate. The latter is an approximate guess rank, not a uniform search space. Long crack times are uncertain forecasts, not guarantees.

How breach checking protects privacy+

Only after you opt in and submit, the worker hashes the exact UTF-8 password with SHA-1. It sends the first five hexadecimal characters over HTTPS to the Have I Been Pwned range API, requesting padded results. The remaining 35 characters stay local and are compared in the worker.

SHA-1 is used for the lookup protocol only. It is unsuitable for storing passwords. HIBP sees your IP address and a hash prefix; it receives neither your password nor the complete hash. A missing match does not prove your password is safe.

The embedded blocklist is small and contains common weak passwords, not a complete breach corpus. If the service is unavailable, the app says the lookup failed.

Have I Been Pwned API documentation
Memory handling & zero retention+

The input clears at submission. UTF-8 bytes transfer to a one-use worker, mutable buffers are overwritten, and only aggregate findings return. The worker is terminated after completion, timeout, reset, or leaving the page. The report never displays secret fragments.

No passwords or reports go to storage, logs, analytics, URLs, service workers, or a backend. Password managers, browser extensions, and a compromised device are outside this app’s control.

JavaScript strings are immutable and garbage collection is controlled by the browser. Physical erasure of every memory copy cannot be guaranteed. This app minimizes lifetime and retention; it cannot promise secure RAM wiping.

For maximum privacy, run the included local server and keep the breach toggle off. Works offline once the bundled files are available.
